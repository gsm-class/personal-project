# 영업일보 시스템 테스트 사양서

## 1. 테스트 개요

### 1.1 목적

영업일보시스템이 요건정의서에 기재된 기능요건·비기능요건을 충족하는지 확인한다.

### 1.2 테스트 범위

- 화면 기능 테스트
- API 기능 테스트
- 데이터베이스 무결성 테스트
- 권한 제어 테스트
- 성능 테스트
- 보안 테스트

### 1.3 테스트 레벨

| 레벨 | 내용 | 실시자 |
| -------------- | ---------------------- | ------------ |
| 단위 테스트 | 개별 기능의 동작 확인 | 개발자 |
| 결합 테스트 | 기능 간의 협력 확인 | 개발자 |
| 시스템 테스트 | 전체 시스템의 작동 확인 | 테스트 팀 |
| 수락 테스트 | 비즈니스 요구 사항 충족 확인 | 사용자 |

## 2. 테스트 환경

### 2.1 하드웨어 환경

- 웹 서버: CPU 4코어, 메모리 8GB
- DB 서버: CPU 4코어, 메모리 16GB
- 클라이언트 PC: Windows 10/11, macOS

### 2.2 소프트웨어 환경

- OS: Linux (Ubuntu 20.04 LTS)
- 웹 서버: Nginx 1.18
- 응용 프로그램 : Node.js 18.x
- 데이터베이스: PostgreSQL 14
- 브라우저: Chrome 최신 버전, Edge 최신 버전, Safari 최신 버전

### 2.3 테스트 데이터

- 영업 담당자: 10명(관리자 2명, 일반 8명)
- 고객: 100개 회사
- 일보: 과거 3개월분(약 600건)

## 8. 테스트 완료 기준

### 8.1 완료 조건

- 모든 테스트 케이스 실시 완료
- 중요도 '높음'의 결함이 제로
- 중요도 '중' 결함이 5건 이하
- 성능 요구 사항을 충족
- 보안 취약점이 발견되지 않음

### 8.2 판정 기준

- 테스트 실시율: 100%
- 테스트 합격률: 95% 이상
- 결함 수렴률: 90% 이상
